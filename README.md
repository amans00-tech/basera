# Basera (built site)

This repository contains the built static site for Basera. Deploy the site to Netlify by connecting this repository or by dragging the built site files into Netlify Drop.

Quick Deploy (Netlify Drop):
1. Go to https://app.netlify.com/drop
2. Drag and drop the contents of this repository's root (index.html, css/, images/) into the drop zone.
3. After deploy, go to Site settings → Domain management to add a custom domain and follow DNS instructions.

Netlify Forms
- The contact form uses Netlify Forms. Submissions will be visible in Netlify dashboard for the site under "Forms".

DNS / Freenom
- If you register a Freenom domain, point its A record or use Netlify's nameservers. See Netlify docs for exact DNS steps.

Notes
- This is the built (static) site. To enable the Netlify CMS admin for in-browser editing, push the full Hugo source and configure Netlify Identity + Git Gateway.
